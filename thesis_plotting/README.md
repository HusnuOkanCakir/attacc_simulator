# thesis_plotting/ — publication-ready figures for the thesis

This directory contains the **thesis figures** as standalone PDFs and
PNGs, the scripts that produce them, and a small shared style module.
It runs in parallel with the existing per-run diagnostic plotters under
`tools/plot_*.py`, not in place of them.

| Folder | Contents |
|---|---|
| [`style/`](style/) | Shared palette + rcParams + helpers (set_spines, bold_legend, save_fig, etc.). All scripts call `configure_plotting()` at the top. See [`style/README.md`](style/README.md). |
| [`scripts/`](scripts/) | One Python file per thesis figure / figure group. They read existing `cluster_outputs/` data — no re-runs needed. |
| [`figures/`](figures/) | Output PDF + PNG per figure. Regenerated by re-running the scripts. |
| [`examples_test/`](examples_test/) | One-shot stub of the `script_configs.parse_results` module from `/home/okan/plotting_examples/`, plus a reproducer that runs `P0_single_detailed.py` against fabricated data so we can visually anchor our style. Scratch — not part of the thesis output. |
| [`PLOTTING_CATALOG.md`](PLOTTING_CATALOG.md) | One-row-per-figure inventory: thesis section, script, PDF, PNG, source sweep. Start here when looking for "which file is figure N". |

## Output format

Every script writes both:

- `figures/<name>.pdf` — vector, paper-ready. If `pdfcrop` is on PATH it
  also gets cropped to remove white margins.
- `figures/<name>.png` — raster preview that embeds inline in markdown
  (used in `PLOTTING_CATALOG.md` and `docs/thesis_results_catalog.md`).

## Regenerating

You need pandas + matplotlib + scikit-learn (for the cost-model
validation figure that loads `.pkl` bundles). The `lerobot` conda env
has everything needed.

```bash
PY=/home/okan/anaconda3/envs/lerobot/bin/python

$PY thesis_plotting/scripts/thesis_e5_gpu_vs_hybrid.py
$PY thesis_plotting/scripts/thesis_e6_bs_sweep.py
$PY thesis_plotting/scripts/thesis_e1_route_share.py
$PY thesis_plotting/scripts/thesis_roofline.py
$PY thesis_plotting/scripts/thesis_predicted_vs_actual.py
```

Each script has a `--help` for overriding the default sweep / cost-table /
output paths.

## Why this folder exists

Our 33 `tools/plot_*.py` scripts were written ad-hoc:
no shared style, inline color choices that drift between scripts,
PNG-only output, no LaTeX bold-math labels, no PDF cropping. The
reference scripts at `/home/okan/plotting_examples/` (P0–P9, from a
Ramulator/RowHammer project) showed a thesis-ready aesthetic worth
adopting: bold-math labels, light category background shading,
dashed-grid + custom spines, dual stacked legends, constrained-layout,
PDF + pdfcrop.

Rather than rewriting all 33 existing scripts, this folder holds the
**publication subset**:

- E5 — the thesis main claim
- E6 — batching findings (1/B disproved + bs=16 starvation)
- E1 — architecture-driven routing divergence
- Roofline — §3 hardware background
- Cost-model validation — §5 methodology

The remaining ~28 diagnostic plotters in `tools/` continue to run
automatically as part of `tools/run_serving_online_policy_compare.py`
sweeps, producing the per-run plots that go into `<sweep>/plots/`.

## Adding a new figure

1. Build a script in `scripts/thesis_<name>.py`:
   ```python
   from thesis_plotting.style import (
       configure_plotting, save_fig, set_spines, bold_legend,
       COLOR_MODEL, COLOR_ROUTE, STD_FIGSIZE,
   )
   configure_plotting()
   fig, ax = plt.subplots(figsize=STD_FIGSIZE)
   # ...
   save_fig(fig, "fig_<name>", Path("thesis_plotting/figures"))
   ```
2. Reuse parsers from `tools/plot_*.py` rather than re-deriving them —
   `sys.path.insert(0, str(REPO / "tools"))` and import directly. See
   `thesis_e6_bs_sweep.py` for the pattern.
3. Add a row to [`PLOTTING_CATALOG.md`](PLOTTING_CATALOG.md) so the
   figure is discoverable.
